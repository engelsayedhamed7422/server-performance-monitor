# Server Performance Stats

A Bash script that displays basic server performance statistics.

## Features

- OS information
- Server uptime
- CPU usage
- Memory usage
- Disk usage
- Top 5 CPU-consuming processes
- Top 5 memory-consuming processes
- Load average
- Logged-in users

## Requirements

- Linux
- Bash

## Installation

Clone the repository:

git clone git@github.com:engelsayedhamed7422/server-performance-monitor.git

Navigate to the project:

cd server-performance-monitor

Make the script executable:

chmod +x server-stats.sh

## Usage

Run:

./server-stats.sh
